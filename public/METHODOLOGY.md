# 調査方法・中立性ポリシー

**対象選挙**：2026年福岡市長選挙（告示：11月1日、投開票：11月15日）  
**資料の閲覧・判定日**：2026年11月6日（日本時間）

## 目的と限界

これは、13人の候補者の公開回答・公約を同じ形式で比較するための一次データ案です。投票の勧誘、候補者の順位付け、公約の実現可能性の採点ではありません。公開資料の詳しさには差があり、「不明」が多いことは政策が少ないことを意味しません。

同性婚と選択的夫婦別姓は国の制度ですが、RKBが13人に同じ質問をした直接回答があるため、考え方の比較として採用しました。市長だけで実現できる政策の有無は、賛否とは別に読む必要があります。

## 質問の作り方

- 一文で答えられる賛否文にし、複数の異なる政策を無理に束ねない。
- 「福祉より成長」「子育てより高齢者」など、特定の価値を当然視する二者択一を避ける。
- 市民の暮らし、都市開発、交通、財政、教育、防災、地域経済、外国人住民、透明性などに分野を分ける。
- 候補者の公約・回答で実際に話題になっている事項を選ぶ。質問数・分野別数を特定候補の見え方に合わせて調整しない。
- 「検討する」「条件付きで賛成」「どちらともいえない」は賛否の違いとして残す。細かな制度の実現性は別情報として確認する。

## 判定値

| stance | 表示 | 使う場合 |
|---:|---|---|
| 2 | 賛成 | 明確な推進、明確な「賛成」、十分／大いに評価など |
| 1 | やや賛成 | 条件付き・検討・段階的推進、「ある程度評価」など |
| 0 | 中立・両論・両立 | 「どちらともいえない」、現時点では判断保留、又は賛否文に対して明確に両立策を答えた場合 |
| -1 | やや反対 | 消極的な評価、「どちらかといえば反対」など |
| -2 | 反対 | 明確な反対・廃止・転換を主張する場合 |
| null | 不明 | 今回確認した資料に、設問へ答える根拠がない場合 |

0は「情報がない」ではなく、**確認できた立場**です。たとえば公共交通と道路整備の選択を求められた回答で「両方」を明確に選んだ場合に用います。一方、質問と違う一般論だけでは0にせずnullとします。nullにも根拠文として「今回確認した公開資料で、明確な賛否を確認できず」を共通で入れています。

## 出典と根拠

1. 候補者・政党の公式サイト、政策集、本人の公開投稿を優先する。
2. FBS・RKB・テレQなどの、全員同じ質問への本人回答を重視する。
3. 選挙公報は候補者が提出した原稿をそのまま掲載したものとして使う。市選管が内容を認定したという意味ではない。
4. 各非nullセルに出典URLと60字以内の引用または忠実な要約を残す。nullを防ぐための要約や推測はしない。
5. 出典は公開ページに依存する。有料会員にならず読めない部分だけを使い、購読者向け全文を復元・転載しない。
6. PDFの選挙公報と神野氏の政策PDFは画像・本文を照合した。ウェブサイトに記載のない情報は推測しない。

## 中立性と個人情報

- 政党名・推薦団体・雰囲気から賛否を推測しない。当選可能性や公約への賛否も判定しない。
- 回答はブラウザ内で処理し、サーバーに送信・保存しない設計を推奨する。属性・投票先・端末情報を送らない。
- データ・質問集のアルゴリズムも公開し、誤りの指摘は出典つきで受け付けるOSS運用を想定する。
- このデータセット自体に利用者の回答は含まない。

## 重点公約の3項目（診断とは別の参考情報）

候補者一覧に掲載する各3項目は、公式サイト・公式政策集で冒頭に置くもの、重点施策の見出し、第一声や本人回答で強調したものから選びます。資料取得が難しい場合は、報道機関が転載した本人の公約・政策回答を補助的に使います。20問への当てはめや、賛否コード・スコアが高い低いで選ぶことはしません。

項目は届出順の候補者それぞれについて同じ形式で作成し、40字以内の中立的な要約と出典URLを`pledges.json`に記録します。原文の目標・検討・推進の強さを実現済みの事実と混同しないよう注意します。出典で重点と確認できる項目が3つに満たない場合は、確認できたものだけを掲載し、その旨を表示します。

これは候補者の訴えを手早く比較する参考情報であり、マッチ度・順位・賛否マップの計算には使いません。政策の網羅的な一覧ではないため、詳細や財源・対象範囲は各出典で確認してください。

## 照合・更新の作業手順

- 新しい公開資料で賛否が変わった場合は古い資料を消さず、変更日と新旧の出典を残す。
- 誤記修正・方針の明確化はIssueやPull Requestで出典つきに行う。
- 公開前に各候補者の全20セルをもう一度目視する。公開後に届く追加資料でnullを更新する。
- 「不明」の多い候補者には質問紙への回答を送る選択肢があるが、今回は誰にも連絡していない。

## 質問を外した論点

子育て支援の国籍要件、外国人労働者の受け入れ、公共料金の具体的な減免、最低賃金1500円、福岡城天守の復元なども選挙の論点です。ただし、今回確認した資料だけでは全員比較に必要な明示回答が不足するため、この20問には入れていません。森氏の国籍要件など確認できた内容自体を消すわけではなく、質問として差し込まないという判断です。

## マッチングの実装上の注意（データ利用者向け）

- 質問ごとの一致度は`1 - |answer - stance| / 4`で0〜1とし、「重視」は2、その他は1として加重平均する。`±1`は対応する方向の「やや賛成／やや反対」、「検討」「条件付き」を強い支持と混同しないための便宜的な処理である。絶対的な政策強度ではない。
- `0`は「どちらともいえない」「バランス・両立」など異なる回答を含む。1や-1との距離を一般化した政治的中立と解釈しない。
- `null`は0に置き換えない。スコアは、利用者が賛否を付けられている候補者だけで計算し、その質問での「比較可能な候補者数」または各人の未回答の多さを結果に併記する。
- 経済4問・都市交通6問だけで合計半分という分野割り当てには、この選挙の質問紙・争点の分布が反映されている。分野別一致率も表示できると、質問構成に左右される印象を減らせる。
- 人物の実行可能性・財源・数値の正確性・法令上の実現可能性は、今回の賛否コードの外にある。疑わしい提案かどうかの真偽判定はしていない。
